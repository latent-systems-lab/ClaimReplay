# Installation

Use the single quickstart in ../README.md. Supported Python: 3.10–3.12.
Core runtime dependencies: none. Install the prepared wheel with --no-index
--no-deps. Source builds additionally use the two pinned build-tool wheels in
build_wheels. Run from an extracted release directory, never from development.
The core and cache mock need no network, API key, dataset, torch or Transformers.
Current optional model pins are not the historical inference environment.
