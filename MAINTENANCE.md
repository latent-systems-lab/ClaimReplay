# Maintenance and contact

Report software bugs and reproduction questions using GitHub Issues at
https://github.com/latent-systems-lab/ClaimReplay/issues after the repository is accessible.
Do not attach native benchmark records, extracted evidence, labels, private model
outputs or credentials. Prefer minimal synthetic examples.

No guaranteed response time, service level or maintenance horizon is promised.
Requests about restricted data should go to its original provider. No dataset or
private-output redistribution service is implied. Authors may revise maintenance
arrangements explicitly in a future version.
